So gehst du vor

  1. Chatcode kopieren, im Spiel in den Chat einfügen und anklicken: Das Item öffnet sich im Handelsposten.
  2. Kaufgebot zum angegebenen Preis mit der angegebenen Stückzahl einstellen.
  3. Sobald das Gebot gefüllt ist, zum Verkaufspreis einstellen (5 % Einstellgebühr, 10 % Steuer beim Verkauf).
  4. Preise vorher im Spiel prüfen: Die Liste wird einmal täglich erstellt.

Persönlicher GW2-API-Key

Erstelle unter account.arena.net/applications einen eigenen Key nur mit den Berechtigungen „account“ und „tradingpost“. Der Key bleibt in deinem Browser und wird ausschließlich an die Konto-Endpunkte von api.guildwars2.com gesendet (als Parameter access_token, wie von der API für Browser vorgesehen). Er erscheint nie in der Adresszeile und wird nicht protokolliert.
